# כתב העיר (city-script)

כלי שילוט עירוני לאשדוד. Vite + React + framer-motion + MapLibre (OpenFreeMap) + Supabase.

- האפליקציה הקיימת בשורש הריפו לא נוגעים בה. כל העבודה בתיקייה city-script/.
- Supabase: פרויקט ASHDODMAP (cbhexpybdggwzyakgagd), משותף. כל טבלה חדשה בקידומת ks_. המיגרציות 001 ו-002 הוחלו (באישור ענת, 17.10.2026): טבלאות ks_, RLS, פונקציות הגשה ומעקב (כולל לפי טלפון), ks_save_site_request, דלי פרטי ks-docs, ונתוני בסיס מ-seed/policy.mjs. שינוי מבני גדול ב-Storage נתקע על נעילה: להריץ עם set lock_timeout. כלי המיגרציה נופל על בקשות ארוכות: לפצל.
- כל כלל נושא סעיף מקור מהמדיניות. אין כלל בלי סעיף.
- Vercel: פרויקט ktav-hair-ashdod, rootDirectory=city-script, ציבורי (ssoProtection כבוי). כתובת: https://ktav-hair-ashdod.vercel.app
- בדיקה: `npm run build && npm run preview`, ואז `node tests/e2e.mjs`. ממתינים ל-response של המוק ולא ל-request (אחרת יש מרוץ).
- הנחיות: לכל סוג שלט חזית סכמטית ב-src/components/SignDiagram.jsx (SVG, מידות וסעיפים ממוספרים + מקרא). סוג שלט חדש מחייב תרשים חדש שם.
- עיצוב: IBM Plex Sans Hebrew דק וגדול בכותרות, Plex Mono בתוויות (בלי ריווח אותיות בעברית). עומק דרך צללים רב־שלביים (--shadow-1..3), ברק עליון (--sheen), רשת אדריכלית ברקע, וקו רחוב בשלוש שכבות בדף הבית (src/components/Skyline.jsx) עם שלט אחד בצבע. אנימציות כניסה ב-CSS ולא whileInView.
- מפה: רובעים מוצגים כנקודה במרכז הרובע (quarters.center), לא כמלבן. המלבנים במסד משוערים ומבלבלים. zoneAt: אזור עם גבול (חוף, נחל) גובר, אחרת הרובע הקרוב עד 3 ק"מ.
- מסלולים: כל מסלול קו על המפה (CityMap lines), ריחוף על כרטיס מדגיש את הקו.
- שלט אתר: כותבים ישירות על השלט (ps-ink). בקשה נשמרת לפי שם הפרויקט, כולל גדר מדברת וטבלתה אם יש. כרגע ב-localStorage (ktav-construction-v1) עד הקמת הטבלאות.
- הדמיית ההיתר: נטענת לתיבה בשלט האתר (לחיצה או גרירה), מוקטנת ל-1400 פיקסל JPEG ונשמרת עם הבקשה (sign.render).
- חזיתות ההנחיות: זרקור (Veil) מעמעם את ההקשר סביב השלט, השלט זוהר, קווי מידה נמתחים, מספרים קופצים. ריחוף על פריט במקרא מדגיש את המספר בחזית ולהפך. בכרטיסי האינדקס השלט נדלק בריחוף.
- כפתורי המערכת (העתקת קישור, שיחת הפיתוח, פרויקט המחקר, התקנה) בתוך כפתור "מערכת" אחד.
- כניסה במייל (Supabase): אם כתובת האפליקציה לא ב-Redirect URLs של הפרויקט, Supabase מחליף את emailRedirectTo ב-Site URL (כאן http://localhost:3000) והקישור במייל נפתח על localhost. נבדק במייל עצמו: redirect_to=http://localhost:3000. תיקון שורש: Authentication > URL Configuration בפרויקט. גיבוי בקוד: src/lib/authRescue.js, טופס "הקישור מהמייל או הכתובת שנפתחה" בדף הצוות (verifyOtp עם token_hash, או setSession מה-hash). מכוסה ב-e2e.
- סימנים: תגיות וכפתורים נושאים סימן (וי, איקס, ?, !, נקודה, תיבת סימון) דרך ::before עם content: "x" / "" כדי שלא ייקרא בקול ולא ישנה שם נגיש. RESULT כולל must (חובה) ו-step (שלב).
- דיווח: סיכה ננעצת (pin) נגררת, וכפתור "המיקום שלי". האנימציה על .pin-body בלבד, כי maplibre מזיז את האלמנט החיצוני ב-transform.
- בלי רענון: DataProvider טוען עם allSettled, ואם משהו נכשל מנסה שוב (1.5, 4, 10, 30 שניות) וגם בחזרה ללשונית או לרשת. e2e מדמה נפילה של 20 שניות.
- PageGuide: בכל דף "מה עושים כאן" עם צעדים, מה נעשה ומה הבא.
- hooks לפני כל return מוקדם. e2e פותח כל דף ישירות מהכתובת כדי לתפוס את זה.
- טעינת מסמך ו"מלא": src/lib/docExtract.js קורא בדפדפן PDF (וסריקה דרך OCR), Word docx, Excel xlsx, CSV, טקסט, HTML, מייל ותמונות; parseFields ממפה לשדות לפי תוויות. OCR עם tesseract.js מוגש מ-/ocr (scripts/copy-ocr.mjs ב-prebuild). רכיב DocImport בהגשה ובלשונית "קליטה ידנית" בצוות. המסמך המקורי נשמר בדלי ks-docs. e2e בודק 6 פורמטים אמיתיים (tests/make-fixtures.mjs).
- דקירה: reverseGeocode (Nominatim reverse) ממלא כתובת בשדה, ואפשר לשנות.
- מעקב: קוד או טלפון נייד; לפי טלפון מוצגת רשימה לבחירה.
- Shell.jsx: בלי AnimatePresence סביב העמוד. motion.div עם key ואנימציית כניסה בלבד, אחרת הקלט שהוקלד נמחק.

## תיקונים של ענת
- שלב 1: לא למזג ל-main, לא להחיל מיגרציה, לא להוסיף פיצ'רים ולא לעצב מחדש עד סקירה.
- בהנחיות, לכל סוג שלט גרפיקה ויזואלית שמתאימה לסוג השלט.
- עיצוב משודרג לפי סקיל end-to-end: עומק, שכבות, גרדיאנטים ותנועה. אף פעם לא שטוח.
- פלטה בגווני אפור קרים (לא בז'). צבע רק למשמעות.
- כל כפתורי המערכת בכפתור "מערכת" אחד. בלי חיצים דקורטיביים.
- רובעים על המפה: לא מלבנים. מסלולים: קווים על המפה.
- שלט אתר: מילוי ישירות על התצוגה הסכמטית, שמירה לפי שם הפרויקט, עם הגדר המדברת וטבלתה באותה בקשה.
- שלט אתר: אפשר להכניס את הדמיית ההיתר לשלט עצמו.
- הנחיות: גרפיקה מונפשת שמבליטה את סוג השלט.
- כניסה במייל חייבת לעבוד באמת: לבדוק את redirect_to בקישור שבמייל (Gmail) לפני מסירה.
- כפתורים ותגיות עם סימנים: וי, איקס, לסמן, שלב, דרישה, חובה, כן, לא (גובר על 'בלי אייקונים' לסימני מצב).
- דיווח: אפשרות דקירת סיכה.
- דפים מקבלים תוכן בלי רענון.
- בכל דף הסבר: מה נעשה ומה צריך להיעשות.
- להכניס מסמך מכל סוג, כפתור "מלא" שממלא את השדות, ושמירה.
- לבנות את כל מאגרי המידע הנדרשים.
- אחרי דקירה: הכתובת בשדה, עם אפשרות לשנות ולשמור.
- מעקב לפי טלפון נייד שמציג את כל הבקשות לבחירה.
